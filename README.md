# 90+ Studio

90+ Futbol kanalının fikir, senaryo, sahne, görev, medya, yayın ve analiz süreçlerini iki telefonda ortak yönetmek için geliştirilen Android uygulaması.

## Özellikler
- Supabase e-posta/şifre girişi ve ekip koduyla ortak çalışma
- Fikir havuzu, içerik panosu ve otomatik üretim kontrol listeleri
- Sahne planı ve Grok prompt arşivi
- Haftalık görev/yayın takvimi
- Görsel, video ve ses arşivi
- Grok destekli 90+ AI içerik asistanı
- Çevrimdışı yerel kayıt ve yeniden bağlantıda senkron
- GitHub Actions ile otomatik APK

## Grok anahtarı
API anahtarını kaynak koda eklemeyin. Supabase Dashboard > Edge Functions > Secrets bölümüne `XAI_API_KEY` adıyla ekleyin.

## APK
GitHub > Actions > Android APK > son başarılı çalışma > Artifacts > `90-PLUS-STUDIO-APK`.
